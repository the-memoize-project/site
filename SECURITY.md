# Política de Segurança

## Versões suportadas

| Versão | Suportada |
|---|---|
| `main` (produção) | ✅ |
| Branches antigas | ❌ |

## Reportando uma vulnerabilidade

**Não abra uma issue pública para relatar vulnerabilidades de segurança.**

Se você descobriu uma vulnerabilidade, envie um e-mail para **[seguranca@memoize.cards](mailto:seguranca@memoize.cards)** com:

1. Descrição detalhada da vulnerabilidade
2. Passos para reproduzir
3. Impacto potencial
4. Sugestão de correção (opcional)

### O que esperar

- **Confirmação de recebimento** em até 48 horas úteis.
- **Avaliação inicial** em até 5 dias úteis.
- **Atualização de progresso** a cada 7 dias enquanto a correção estiver em andamento.
- **Crédito público** na release notes (se desejar) após a correção ser implantada.

Agradecemos a divulgação responsável e o apoio para manter o Memoize seguro para todos os usuários.
